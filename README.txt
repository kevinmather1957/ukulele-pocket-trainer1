
Ukulele Pocket Trainer — Full (Version 2)
-----------------------------------------
- Songs loaded in fixed keys (as provided). No transpose (option A selected).
- Installable PWA: open index.html in Safari -> Share -> Add to Home Screen OR use Install button if prompted.
- Tap Play to start backing loop. Tap chords to preview plucked ukulele voicings.
- The Karplus-Strong like pluck is a lightweight approximation for offline use.
- To update songs or add exact progressions, edit songs.json with arrays of chords for each song.
